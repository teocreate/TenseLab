# TenseLab

PWA-тренажёр английских времён на Vanilla JavaScript. Пользователь выбирает время, собирает предложение из слов и сразу получает обратную связь.

## Возможности

- 24 темы, 20 шагов практики в каждой;
- оригинальный Grammar Lab с проверочными модулями по базовым темам грамматики;
- случайные предложения при каждом новом задании;
- лишние формы глаголов из соседних времён: нужно выбрать не только правильный порядок слов, но и нужное время;
- мгновенная проверка, подсказка и озвучивание;
- локальные дневные цели, XP, серии дней и экспорт результата;
- PWA: установка на домашний экран iOS и офлайн-работа после первого запуска.

## Локальный запуск

Это статический сайт без зависимостей. Откройте `index.html` в браузере либо запустите любой локальный HTTP-сервер:

```bash
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Добавьте удалённый адрес: `git remote add origin <URL-репозитория>`.
3. Выполните `git add .`, `git commit -m "Initial TenseLab"` и `git push -u origin main`.
4. В **Settings → Pages** включите публикацию из ветки `main`, папка `/ (root)`.

Для установки PWA на iPhone откройте опубликованный HTTPS-адрес в Safari и нажмите «Поделиться → На экран “Домой”».
